# Decisões arquiteturais

| ADR | Status | Resumo |
| --- | --- | --- |
| — | — | Nenhum ADR registrado até o momento. |

Crie um ADR para uma decisão arquitetural duradoura com alternativas ou consequências relevantes. Numere sequencialmente como `0001-assunto.md`. Um ADR aceito é imutável; mudanças posteriores recebem novo ADR, com referência ao anterior. Decisões retroativas devem informar a data original, a data de registro e o status `Aceito (retroativo)` quando houver evidência.

## Modelo

```md
# Título

- Status: Proposto
- Data: AAAA-MM-DD

## Contexto

## Decisão

## Consequências
```
